# GitHub PR template

A GitHub PR template for small engineering teams. Copy this file to `.github/pull_request_template.md` so GitHub attaches it to every pull request.

A pull request is a request for someone else to take on risk. Write it that way. Four short sections beat a blank description.

## What
<!-- Two or three sentences. The problem, not the implementation tour. -->

## How to check
<!-- Commands, screenshots, or a preview link. -->

## Risk and undo
<!-- What happens if this is wrong, and how we roll it back. -->

## Deliberately not doing
<!-- Scope you are leaving on the floor. -->

## Definition of Done

- [ ] The change solves the stated problem.
- [ ] You can explain it in two or three sentences.
- [ ] Existing tests pass, or the PR says why not.
- [ ] No secrets in the diff.
- [ ] Someone else has reviewed it.
- [ ] Preview / staging has been checked for the path you changed.
- [ ] You know how to undo it.
